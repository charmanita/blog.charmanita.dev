I have pitched an idea of making a sort of universal model converter for the glTF models provided by [mii.nxw.pw](https://mii.nxw.pw), more specifically [FFL.js](https://github.com/ariankordi/FFL.js), provided by [Arian](https://github.com/ariankordi). We have already started talking about this idea of making the Mii data export not just to glTF, but also other model formats like DAE or FBX for [Tower Unite](https://store.steampowered.com/app/394690/Tower_Unite/) and MDL for Source games like [Garry's Mod](https://store.steampowered.com/app/4000/Garrys_Mod/).

I'm pretty excited about this project since it'll help me start using C++ in a way that interests me, and I really just feel like it would be a good way to try new things (since I have not worked much with transforming data into 3D models and all that jazz...)
